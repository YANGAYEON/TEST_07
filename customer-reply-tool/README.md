# 고객 문의 정리 도구

상단 탭에서 두 기능을 전환해 사용합니다.

| 탭 | 방향 | 하는 일 |
|---|---|---|
| 고객 답변 정리 | 개발자 → 고객 | 확인 결과·조치 내용을 고객에게 보낼 답변으로 정리 |
| 요구사항 정리 | 고객 → 개발자 | 메신저로 받은 고객 요청을 개발자용 요구사항으로 요약·정리 |

## 실행
`index.html` 을 브라우저(Chrome / Edge 권장)로 열면 됩니다. 설치·서버·인터넷 연결이 필요 없습니다.

## 고객 답변 정리
1. **서술형 입력** — 메모하듯 편하게 입력 (예시 불러오기, `Ctrl+Enter`로 정리)
2. **자동 분류** — 문의 내용 / 확인 결과 / 원인 / 조치 내용 / 고객 안내사항
   - 분류가 틀리면 항목을 직접 바꾸거나 체크를 해제해 답변에서 뺄 수 있음
   - 추정 표현, 내부 정보로 보이는 문장(코드·쿼리·IP 등)은 표시
3. **답변 정리** — 반말·메모체 → 합쇼체, 전문 용어 순화(선택), 사과 문구(선택)
4. **형식 선택** — 간결형 · 정중형 · 상세형
5. **미리보기** — 직접 수정 가능, 글자 수 표시
6. **복사** — 버튼 한 번으로 클립보드에 복사

## 요구사항 정리
고객 요청 원문을 붙여넣으면 아래 형식으로 정리합니다.
```
[요구사항 요약]   신청 화면의 입력 편의성 개선 및 신청 상태별 처리 기능 추가
[현재 상황]       고객이 말한 불편·현황 (선택)
[세부 요구사항]   1. 신청일자 자동 입력
                     * 화면 최초 진입 시 오늘 날짜를 기본값으로 설정한다.
[고객 문의 사항]  고객이 질문한 문장 (있을 때만)
[확인 필요 사항]  모호한 부분을 고객에게 확인할 질문으로 정리 (선택)
```
- 문장을 요구사항 / 현재 상황 / 문의 / 제외로 자동 구분하고, 직접 바꿀 수 있습니다.
- 고객이 말하지 않은 요구사항은 만들지 않습니다. 정해지지 않은 부분(색상, 권한 범위 등)은 '확인 필요 사항'에 질문으로만 남깁니다.
- '원문 문장 함께 표시'를 켜면 각 요구사항 아래에 고객 원문이 같이 나옵니다.

## 처리 원칙
- 입력에 없는 원인·조치·사실을 만들지 않습니다. 문장은 어미와 표현만 다듬습니다.
- 추정 표현(“~것 같음”, “아마”, “~일 수도”)은 “~로 보입니다 / 추정됩니다”로 바꾸고, 원인이 추정이면 안내 문구를 붙입니다.
- 확인 결과·원인·조치 내용이 없으면 답변에 `[추가 확인 필요: 항목]` 을 노란색으로 표시합니다.
- 외부 API·네트워크·저장소(localStorage 등)를 사용하지 않습니다. 입력 내용은 페이지를 닫으면 사라집니다.

## 구성
```
index.html        화면
css/styles.css    스타일 (라이트/다크 모드, 모바일 대응)
js/engine.js      규칙 기반 분류·문장 정리 엔진 (외부 라이브러리 없음)
js/app.js         고객 답변 정리 화면
js/requirements.js 요구사항 요약·정리 엔진
js/req-app.js     요구사항 정리 화면, 탭 전환
test/*.js         엔진 확인용 스크립트 (node test/run.js, node test/req.js)
```
분류·변환 규칙은 `js/engine.js` 의 `RULES`, `CASUAL`, `JARGON`, `js/requirements.js` 의 `TYPES`, `PHRASE`, `VAGUE` 에서 수정할 수 있습니다.
