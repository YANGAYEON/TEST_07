# 파일명 일괄 변경기 (Batch File Renamer)

`index.html` 단일 파일로 동작하는 파일명 일괄 변경 프로그램입니다.
서버·설치·인터넷 연결·외부 라이브러리 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

1. `index.html` 파일을 더블클릭해 Chrome / Edge / Firefox / Safari 등 최신 브라우저로 엽니다.
2. 끝. (인터넷 연결 불필요)

## 사용 방법

1. **파일 추가**: 상단 영역에 파일이나 폴더를 끌어다 놓거나 `파일 선택` / `폴더 선택` 버튼을 누릅니다.
2. **변경 규칙 설정**: 왼쪽 패널에서 사용할 규칙의 스위치를 켜고 값을 입력합니다. 값을 입력하면 해당 규칙이 자동으로 켜집니다.
3. **순서 조정**: 순번은 파일 목록 순서대로 부여됩니다. ▲▼ 버튼이나 `순서 정렬…` 메뉴로 순서를 바꿉니다.
4. **미리보기 확인**: 변경 부분이 색으로 강조됩니다. (초록=추가, 보라=치환, 빨강 취소선=삭제, 노랑=자동 수정)
5. **다운로드**: `변경 파일 다운로드` 버튼을 누릅니다.
   - 1개 파일 → 새 이름으로 바로 다운로드
   - 여러 파일 → `ZIP으로 묶기`(기본) 또는 `개별 파일로` 중 선택

## 규칙 적용 순서

```
[순번(앞)][날짜(앞)][접두어][치환된 파일명][접미어][날짜(뒤)][순번(뒤)].[확장자]
```

1. 문자열 치환 (기본적으로 확장자 제외, 옵션으로 포함 가능)
2. 접두어 → 3. 접미어 → 4. 날짜 → 5. 순번 (날짜·순번이 가장 바깥에 위치)

## 검증 항목

| 항목 | 처리 |
|---|---|
| 변경 후 파일명 중복 (대소문자 무시 옵션) | 다운로드 제한, 또는 `자동 번호` 옵션으로 `이름 (1).ext` 부여 |
| 빈 파일명 | 오류 |
| 사용할 수 없는 문자 `\ / : * ? " < > |` 및 제어문자 | 오류, 또는 `_`로 자동 변경 옵션 |
| 공백/마침표로 끝나는 이름, Windows 예약어(CON, NUL 등), 255자 초과 | 오류 |
| 기존 이름과 동일 | "변경 없음"으로 표시 (다운로드는 가능) |

## 보안 및 제한사항

- 파일은 어떤 서버로도 전송되지 않으며, 모든 처리는 브라우저 메모리 안에서 이루어집니다.
- 파일 **내용**은 ZIP을 만들 때(CRC 계산)만 읽습니다. 파일 추가·미리보기 단계에서는 이름·크기·수정일만 사용합니다.
- 브라우저 보안 정책상 웹 페이지는 디스크의 원본 파일 이름을 직접 바꿀 수 없습니다. 그래서 **새 이름의 복사본을 다운로드**하는 방식이며, 원본은 수정·삭제되지 않습니다.
- ZIP은 외부 라이브러리 없이 직접 구현했으며 **무압축(STORE) 방식**입니다. 묶기만 하므로 용량은 줄지 않지만 빠르고 파일이 손상되지 않습니다. 한글 파일명은 UTF-8 플래그로 저장되어 Windows 탐색기·macOS·반디집 등에서 정상 표시됩니다.
- ZIP64를 지원하지 않으므로 ZIP 전체 4GB 미만, 최대 65,535개 파일까지 가능합니다. 이를 넘으면 `개별 파일로` 다운로드를 이용하세요.
- `개별 파일로` 다운로드 시 브라우저가 "여러 파일 다운로드 허용"을 물을 수 있습니다. 허용해야 모든 파일이 저장됩니다.
- 폴더를 드롭하면 하위 폴더의 파일까지 평탄하게(폴더 구조 없이) 목록에 추가됩니다.
- 변경 규칙과 테마 설정은 편의를 위해 브라우저 localStorage에 저장됩니다(파일 정보는 저장하지 않음).
